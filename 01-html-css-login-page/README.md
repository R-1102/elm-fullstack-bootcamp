# HTML & CSS Login Page

A simple login page developed during the Full-Stack Development track of Elm's Bootcamp.

## Overview

This project was an introductory exercise in front-end development, focusing on HTML structure, CSS styling, and basic user interface design.

## Features

- Username and password input fields
- Gradient background
- Styled login button
- CSS hover effects

## Technologies

- HTML5
- CSS3

## Getting Started

Clone or download the repository and open `index.html` in your browser.

## Project Structure

    html-css-login-page/
    ├── index.html
    └── README.md

## Learning Outcomes

- Understanding basic HTML elements
- Styling input fields and buttons using CSS
- Applying gradients and hover effects
- Building a simple login interface

## Note

This project is a static front-end exercise. It does not include backend integration or authentication functionality.

Developed as part of Elm's Full-Stack Development Bootcamp.
