# HTML & CSS Login Page

An introductory front-end development exercise completed during Elm's Full-Stack Development Bootcamp.

## Overview

A simple login interface built using HTML and CSS, focusing on page structure, form elements, and responsive styling.

## Technologies

- HTML5
- CSS3

## Features

- Username and password fields
- Responsive layout
- Gradient background
- Accessible input labels
- Button hover and focus effects

## Getting Started

Open `index.html` in any modern web browser.

## Note

This is a static learning exercise and does not include authentication or backend integration.

The original implementation was later refined to improve code readability, accessibility, and styling.
