# Tech Job Portal

An ASP.NET Core MVC web application for browsing, searching, and filtering technology-related job listings.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** February 27, 2025
- **Technologies:** C#, ASP.NET Core MVC, .NET 9, HTML5, CSS3, Bootstrap, Razor

## Features

- Job listings with title, company, location, and posting date.
- Job search by title or company name.
- Filtering by job type (Full-time, Part-time, Remote, Contract).
- Dedicated job details pages.
- Responsive user interface using Bootstrap.
- MVC architecture.

## Getting Started

Ensure the .NET 9 SDK is installed, then run:

```bash
dotnet run --project TechJobPortal.csproj
```

Open the local URL displayed in the terminal.

## Note

This is an educational web application that uses sample in-memory job listings rather than live vacancies or an external database.
