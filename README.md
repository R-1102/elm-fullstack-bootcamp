# Amazon Order Management System - Java
## Overview
This project is a backend order management system designed for a simulated e-commerce platform, similar to Amazon.sa. The application demonstrates key Object-Oriented Programming (OOP) principles such as Inheritance, Polymorphism, and Encapsulation, and includes a basic order management system where products can be added to an order and processed based on availability.

- Different product types
 ## Technologies
