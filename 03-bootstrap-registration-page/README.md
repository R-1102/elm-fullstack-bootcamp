# Bootstrap Registration Page

A simple account registration interface built using HTML and Bootstrap, featuring username, password, email, and phone number fields.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** February 18, 2025
- **Technologies:** HTML5, Bootstrap 5

## Features

- Account registration interface.
- Username, password, email, and phone number fields.
- Responsive layout using Bootstrap's grid system.
- Image integration.

## Getting Started

Open `index.html` in a web browser. An internet connection is required to load Bootstrap from the CDN.

## Note

This is an educational front-end exercise without backend registration or authentication.
