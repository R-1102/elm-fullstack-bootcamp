# Amazon Order Management System — ASP.NET (Basic)

An ASP.NET Core MVC web application inspired by Amazon's e-commerce platform, demonstrating basic product management and customer order processing.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** March 1, 2025
- **Technologies:** C#, ASP.NET Core MVC, .NET 9, HTML5, CSS3, Razor

## Features

- Product listings and management.
- Customer order creation through an order-entry form.
- Order history.
- In-memory product and order collections.
- MVC architecture and HTTP routing.

## Getting Started

Ensure the .NET 9 SDK is installed, then run:

```bash
dotnet run --project AmazonOMS_.csproj
```

Open the local URL displayed in the terminal.

- `/Products` — Browse products.
- `/Order/Place` — Place an order.

## Note

This is an educational implementation of an order management system without stock tracking, database integration, or official Amazon services.
