# Amazon Order Management System — ASP.NET (Stock)

Amazon-inspired educational e-commerce simulation with product list, stock quantities, order creation, subtotals and order history. Data is in memory; no real Amazon integration.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** March 1, 2025
- **Technologies:** C#, ASP.NET Core MVC, .NET 9

## Getting Started

With a .NET 9 SDK: `dotnet run --project AmazonOMS.csproj`. Open the local URL printed by the CLI.
