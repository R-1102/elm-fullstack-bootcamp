# Amazon Order Management System — ASP.NET (Stock)

An ASP.NET Core MVC web application inspired by Amazon's e-commerce platform, demonstrating product management, inventory tracking, and customer order processing.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** March 1, 2025
- **Technologies:** C#, ASP.NET Core MVC, .NET 9, HTML5, CSS3, Razor

## Features

- Product listings with available stock quantities.
- Inventory management and stock availability checks.
- Customer order creation and processing.
- Automatic stock updates after order placement.
- Order subtotal and total price calculations.
- Order history.
- In-memory product and order collections.
- MVC architecture and HTTP routing.

## Getting Started

Ensure the .NET 9 SDK is installed, then run:

```bash
dotnet run --project AmazonOMS.csproj
```

Open the local URL displayed in the terminal.

## Note

This is an educational implementation of an order management system with inventory tracking. It uses in-memory data without database integration or official Amazon services.
