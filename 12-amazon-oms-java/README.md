# Amazon Order Management System — Java

A Java-based order management system inspired by Amazon's e-commerce platform, demonstrating product management, inventory tracking, and order processing using object-oriented programming principles.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** March 1, 2025
- **Technologies:** Java, OOP, Collections, Git, GitHub

## Features

- Product management with different product types.
- Inventory tracking and stock availability checks.
- Customer order creation and processing.
- Order total calculation and order history.
- Object-oriented programming, including inheritance, polymorphism, and encapsulation.
- Exception handling and Java Collections.

## Getting Started

Ensure Java JDK is installed, then run:

```bash
javac -d out src/*.java
java -cp out Main
```

## Note

This is an educational console-based application inspired by Amazon's order management system. It uses in-memory data without database integration or official Amazon services.
