# Amazon Order Management System — Java

Amazon-inspired educational console e-commerce simulation with product subclasses, stock checking, order creation and order history. Data is in memory; no real Amazon integration.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** March 1, 2025
- **Technologies:** Java, OOP, Collections

## Getting Started

With a JDK: `javac -d out src/*.java` then `java -cp out Main`.
