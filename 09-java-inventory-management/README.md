# Inventory Management System

A Java-based inventory and order management system designed to simulate stock tracking, restocking predictions, and customer order processing using object-oriented programming principles.

Developed as part of Elm's Full-Stack Development Bootcamp.

- **Project Date:** February 26, 2025
- **Technologies:** Java, Git, GitHub

## Features

- Product inventory and stock level tracking.
- Stock depletion predictions based on average daily sales.
- Restocking recommendations.
- Customer order processing classes.
- Multithreading for order status updates.
- Object-oriented programming and exception handling.

## Getting Started

Ensure Java JDK is installed, then run:

```bash
javac -d out src/*.java
java -cp out Main
```

## Note

This is an educational console-based application inspired by enterprise inventory management systems. Order processing is implemented separately and is not invoked by the main application.
